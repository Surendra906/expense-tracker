# Expense Tracker Backend

A REST API backend project built using Spring Boot and MySQL for managing daily expenses.

## Features

- Add expenses
- Update expenses
- Delete expenses
- View all expenses
- Pagination support
- MySQL database integration

## Tech Stack

- Java
- Spring Boot
- Maven
- MySQL
- Spring Data JPA
- Hibernate

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /expenses | Get all expenses |
| POST | /expenses | Add new expense |
| PUT | /expenses/{id} | Update expense |
| DELETE | /expenses/{id} | Delete expense |

## Run Project

Clone repository:

git clone https://github.com/Surendra906/expense-tracker.git

Run project:

mvn spring-boot:run
